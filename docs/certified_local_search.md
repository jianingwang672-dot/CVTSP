# Certified fixed-solution upper bound and local search

This is the first stage of the self-improvement plan.  It deliberately does
not include pseudo-expert imitation learning or an edge-cost predictor.

## Mathematical contract

For an anchor tour `q`, Gurobi returns visit-position arrays `s[k]`, `l[k]`,
`t1[k]`, `t2[k]`, and `tau[k]`.  `FixedSolutionUpperBound` relabels those
arrays by the target id `q[k]`.

After relabeling, all target-local constraints remain feasible under any tour:

- UAV outbound distance and `t1`;
- UAV inbound distance and `t2`;
- `tau = t1 + t2` and the endurance bound;
- synchronization between the same target's takeoff and landing points.

Only carrier adjacency changes.  With depot `d` and carrier speed `Vc`, the
directed carrier-time matrix is

```text
c[0,j] = ||d - s[j]|| / Vc
c[i,j] = ||l[i] - s[j]|| / Vc
c[i,0] = ||l[i] - d|| / Vc
```

For candidate tour `r=(r1,...,rn)`, the reused feasible objective is

```text
UB(r) = sum_i tau[i]
      + c[0,r1]
      + sum_k c[rk,r(k+1)]
      + c[rn,0].
```

Consequently, the re-optimized fixed-tour value obeys `V(r) <= UB(r)` up to
the explicitly checked solver tolerance.  A move is considered only when

```text
UB(r) < current_exact_objective - epsilon.
```

The offline legacy experiment can refresh Gurobi after an accepted move.  The
formal joint-training path instead holds this one anchor table fixed for the
whole chain, performs up to 30 accepted moves with zero intermediate solver
calls, and makes only one optional final expert solve.

The matrix is asymmetric.  The formal fixed-anchor search uses exact
incremental deltas; its 2-opt delta includes every reversed internal directed
edge rather than using the symmetric-TSP four-edge formula.  A full route-sum
invariant is checked before every accepted move.

## Solver formulation

The existing general-norm formulation remains the default baseline.  The
certified path enables `SolverConfig.gurobi_explicit_qcp`, which expresses the
same Euclidean norm inequalities as explicit convex quadratic constraints.
This avoids larger general-constraint residuals observed on some real tours
and permits a stricter feasibility audit without changing baseline behavior.

## Correctness gate

The verification script builds random anchors, tests full random permutations
and random swap/relocate/asymmetric-2-opt moves, and independently solves every
candidate with Gurobi.

```bash
python3 verify_certified_upper_bound.py \
  --instances 5 \
  --candidates-per-instance 20 \
  --problem-size 10 \
  --real-instance-path instance/Data/Example_1.txt \
  --real-instance-path instance/Data/Example_2.txt \
  --seed 20260812 \
  --threads 1 \
  --output-json outputs/certified_upper_bound/verification_j10_random_and_real_seed20260812.json
```

The command exits non-zero if any candidate violates
`true_objective <= upper_bound + tolerance`.

## Local-search experiments

Random initial tour:

```bash
python3 run_certified_local_search.py instance/Data/Example_1.txt \
  --initial-tour random \
  --seed 20260812 \
  --threads 1 \
  --max-refreshes 10 \
  --output-json outputs/certified_local_search/example_1_random_seed20260812.json
```

Tour generated by an existing model checkpoint:

```bash
python3 run_certified_local_search.py instance/Data/Example_2.txt \
  --initial-tour model \
  --checkpoint-path outputs/train_time_test/best.pt \
  --model-device cpu \
  --model-pomo-size 10 \
  --threads 1 \
  --max-refreshes 10 \
  --output-json outputs/certified_local_search/example_2_model_train_time_test_best.json
```

Each JSON file contains every accepted move, its predicted upper bound, the
refreshed true objective, feasibility residual, evaluated-move count, accepted
move count, Gurobi-call count, and runtime.
