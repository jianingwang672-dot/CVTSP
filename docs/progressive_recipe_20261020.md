# 渐进搜索方案：从头训练（2026-10-20）

## 依据

- S500在E100后退步，按J拆分：小J（J20–J60）约在E60–E100达到最好后持续退步，J100持续进步；原因是POMO多样性塌缩（见 `docs/e100_plateau_branches_20261019.md`）。
- 塌缩的三个推手：IL标签量（near-miss 5%/10%/20%对照）、基于上界C0的RL奖励、搜索算子（LKH≈swap>2-opt）。
- 冻结策略下swap+2-opt与LKH高度互补（两者取最好：改善1.04%，单独约0.65%）；训练中LKH单独使用时会关掉near-miss通道。
- E100分支中strong_expert（near-miss 100%＋2轮C0刷新）只对大J有效。

## 配置

以恢复的S500配置为基础（`train_joint_self_improvement.py` 默认值），训练器为 `src/ProgressiveRecipeTrainer.py`，入口为 `scripts/train_progressive_recipe.py`，启动脚本为 `scripts/train_progressive_recipe_tmux.sh`（tmux会话 `cvtsp_progressive_recipe`，32个worker，CPU 0–31）。

与S500相同：seed 20260813与训练实例流、学习率（余弦，总长500轮，1e-4→1e-7，warmup 1；训练只跑200轮，所以E1–E200的学习率与S500逐轮一致）、每轮1万实例、batch 64、Top-K 30（质量20＋多样性10）、IL 5遍、replay 30%/50000、RL奖励、Reference规则。

改动：

| 项目 | 设置 |
|---|---|
| 局部搜索 | 去掉swap，只用2-opt（最多30步） |
| 大J（J≥60）的渐进强化 | ramp r=clip((epoch−40)/60, 0, 1)：LKH起点比例r×0.5（其余2-opt，LKH时间预算按比例缩放）；near-miss率=自适应率+r×(1−自适应率)，E100起为100%；E61起每batch做2轮C0刷新 |
| 小J（J<60） | 始终只用2-opt、S500的自适应near-miss（1–5%）、不刷新 |
| IL总量归一化 | 每个J的改进Expert重复权重按 (1.44−(1−c))/c 计算并截到[1,5]（c为本轮该J的改进比例），使每实例IL样本量保持约1.44（S500在E100附近的水平）；小数权重用独立随机数做随机取整 |
| 训练内固定验证 | 新的1000例（每个规模200，seed 20261020，`validation/progressive_recipe_20261020/val1000`），协议同S500（每例1条free-start greedy，Gurobi精算）；与macsim_fixed、pomo_selection、validation2000、test500、诊断集及人工5000逐例查重均无重复 |

换了训练内验证集后，Reference的晋升时点可能和S500不同，所以S500是非常接近、但不是逐位等价的对照。

## 选模与测试

- 选模：训练结束后，`select_after_training.sh`（tmux会话 `cvtsp_recipe_select`）在 `validation/e500_logic_e100_20261010/validation2000`（2000例，每个规模400）上做完整POMO评测（greedy、POMO=J、精算所有候选取最优），覆盖新方案和S500的E10–E200（每10轮一次），基线为S500-E100。
- 最终测试只做一次：test500（`validation/e500_logic_e100_20261010/test500`，500例，每个规模100，seed 20262010，从未评测过）和Real529；对比G200和S500-E100。不再使用人工5000。

## 启动核验

- 单元测试 `tests/test_progressive_recipe.py`（按J/按epoch的参数、IL权重与样本量、LKH起点选择），全部110个测试通过。
- 满强度冒烟（ramp从第1轮开始）：大J的batch中混合搜索和刷新正常运行；在J100实例上单独调用：15个起点走LKH（15次LKH调用，预算0.75秒），15个走2-opt，16条不同终点；C0刷新正常精算并判定候选。
- 正式启动后前5个batch的J序列和第一个batch的Anchor与S500一致；Expert较弱（第1个batch的dV为83.5，S500为94.5），是去掉swap的预期结果。
