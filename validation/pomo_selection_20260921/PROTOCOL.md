# 独立 POMO checkpoint 选模集（2026-09-21 冻结）

- 实例：J=20/40/60/80/100，各 200 例，共 1000 例；独立 seed=20260921。原始实例保存在同目录 J*.pt，`manifest.json` 固定内容指纹与文件 SHA-256。
- 创建时确认与旧固定验证集 1000 例、人工测试集 5000 例，以及 Epoch 300 checkpoint 中 50000 条 replay 实例无相同内容指纹。训练使用另一个随机流；训练过程中未保存的全部历史随机实例无法逐例枚举。
- 指标：greedy，POMO=J，nearest_depot，不使用 8 倍增强或 free-start；对每条不同路线使用单线程 Gurobi 精确求解，取该模型在该实例的最小 makespan。
- 每个 checkpoint 用完全相同的 1000 个实例。按总体平均 makespan 从低到高排序；各 J 均值和相对 Epoch 100 的配对置信区间同时报告。此集仅用于选模，不充当最终泛化测试。
- 首先检查 Epoch 100、178、296；随后检查 Epoch 90、95、105、110、120、80、140、160、180、200、220、240、260、280、300、60；从 Epoch 320 到 500 每 20 个 epoch 检查一次。检查点顺序只决定运行先后，最终排名使用同一指标。
- 评测在 CPU 0–15 的 tmux 会话中进行；训练继续使用原来的 GPU 与 CPU 16–31。worker 数只影响速度，失败时可从保存的逐例结果断点续跑。
