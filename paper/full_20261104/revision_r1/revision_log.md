- The ARS patch toolchain (`ars_anchorize_draft.py`, `ars_apply_revision_patch.py`) parses Markdown blocks only and rejects LaTeX, so it was not used. The revision was made as targeted edits on a copy. There is no 1.3 apply report or authorization witness for this round. The full change set is in `main_vs_draft.wdiff.txt` (git word diff).
- Each edit covers a roadmap item that the author decided in the guided review. Part 4 items remain placeholders; Part 5 items were not applied.
- The abstract was edited because roadmap R-2 and R-3 change the claims it states. It was not regenerated by the abstract agent; Phase 5b is still pending.
- Every number added to the manuscript was re-derived from raw files in this session (see the last section). Reviewer statements that could not be checked from local files carry a red placeholder in the text.
