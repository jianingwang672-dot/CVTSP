## 不可混淆的边界

“仅展示八视角质量结果”不等于历史模型选择也用八视角。E133 实际是在原无增强验证协议下选出的。本轮没有重新选择检查点，没有将选型过程伪称为八视角，选型来历在 §5.1 明确保留，但不展示无增强验证成绩。

求解器调用数、训练时间、训练时上界与专家成本等是训练资源或训练机制诊断，不是不同解码协议下的策略质量评估。完整 Gurobi 和元启发式也不是 POMO 几何增强解码，未给它们伪造增强标签。

本轮因作者要求“全部”统一展示协议，在 §5 以外仅清理与无增强结果直接相关的方法论证及讨论、结论句子。摘要不重新生成，其既有质量数字本来就来自八视角结果；问题定义、理论证明、算法及原始实验记录没有改动。旧讨论中的 CPU 预算重复统计问题不属于本轮增强协议范围，仍待另行授权修正。
